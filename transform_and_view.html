💻 Metóda 3: Lokálny príkazový riadok

Ak máte nainštalovaný xsltproc alebo podobný nástroj:

# Transformácia XML na HTML xsltproc invoice_template_simple.xslt invoice_data.xml > faktúra.html # Otvorenie v prehliadači start faktúra.html (Windows) open faktúra.html (macOS) xdg-open faktúra.html (Linux) # Konverzia do PDF pomocou wkhtmltopdf wkhtmltopdf faktúra.html faktúra.pdf

🛠️ Metóda 4: Node.js script

Pre automatizované generovanie:

npm install xslt-processor puppeteer # Vytvorte súbor generate-pdf.js const fs = require('fs'); const puppeteer = require('puppeteer'); const { transform } = require('xslt-processor'); async function generatePDF() { const xml = fs.readFileSync('invoice_data.xml', 'utf8'); const xslt = fs.readFileSync('invoice_template_simple.xslt', 'utf8'); const html = transform(xml, xslt); const browser = await puppeteer.launch(); const page = await browser.newPage(); await page.setContent(html); await page.pdf({ path: 'faktúra.pdf', format: 'A4', printBackground: true }); await browser.close(); } generatePDF();

⚠️ Dôležité poznámky:

  • Print CSS: XSLT šablóna obsahuje @media print štýly pre optimálnu tlač
  • Farby: V nastaveniach tlače zapnite "Tlačiť pozadie" pre farebné logo
  • Veľkosť papiera: Šablóna je optimalizovaná pre A4 formát
  • Kompatibilita: Testované v Chrome, Firefox, Edge

🎯 Odporúčaný postup:

  1. Vygenerujte HTML - stlačte tlačidlo "Vygenerovať faktúru" vyššie
  2. Skontrolujte vzhľad - uistite sa, že faktúra vyzerá správne
  3. Tlačte do PDF - stlačte "Tlačiť ako PDF" alebo Ctrl+P v prehliadači
  4. Uložte PDF - vyberte "Uložiť ako PDF" v tlačovom dialógu
