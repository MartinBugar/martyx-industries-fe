Test XSLT faktúry

Inštrukcie na testovanie:

Pre testovanie XSLT transformácie faktúry boli vytvorené nasledujúce súbory:

1. invoice_data.xml - XML súbor s namockovanými dátami faktúry
2. invoice_template.xslt - XSLT šablóna pre transformáciu XML na HTML

Ako testovať transformáciu:

  1. Online XSLT procesory:
    • FreeFormatter XSL Transformer
    • XSLT Test Tool
  2. Príkazový riadok (ak máte nainštalovaný xsltproc): xsltproc invoice_template.xslt invoice_data.xml > output.html
  3. Programovo (JavaScript/Node.js):

    Môžete použiť knižnice ako xslt-processor alebo saxon-js

Funkcionalita XSLT šablóny:

  • ✅ Presná reprodukcia vzhľadu faktúry z obrázka
  • ✅ Responsive dizajn pre rôzne veľkosti obrazovky
  • ✅ Podpora tlače (@media print)
  • ✅ Automatické formátovanie čísel a dátumov
  • ✅ Dynamické tabuľky položiek
  • ✅ Automatické výpočty súčtov
  • ✅ Farebné logo (CSS gradient)
  • ✅ Profesionálny vzhľad s hranicami a štýlmi

Prispôsobenie:

Pre zmenu dát faktúry jednoducho upravte súbor invoice_data.xml. Pre zmenu vzhľadu upravte CSS štýly v súbore invoice_template.xslt.

Podpora PDF:

Pre generovanie PDF môžete použiť:

  • Webový prehliadač (Ctrl+P → Uložiť ako PDF)
  • Nástroje ako wkhtmltopdf, Puppeteer, alebo Prince XML
  • FO procesory ako Apache FOP (vyžaduje konverziu na XSL-FO)
